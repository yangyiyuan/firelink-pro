# FireLink Pro - 智慧消防通信协议模拟器

基于 GB/T 26875.3-2011《城市消防远程监控系统 第3部分：报警传输网络通信协议》标准的专业级消防报警通信模拟器，为智慧消防/物联网平台提供场景化测试能力。

## 项目背景

随着物联网技术的快速发展，智慧消防已成为城市安全建设的重要组成部分。用户信息传输装置（ADU）作为连接前端消防设备与后端监控平台的关键枢纽，其通信协议的正确性直接关系到火灾报警信息的准确传输和及时响应。

GB/T 26875.3-2011 国家标准规定了城市消防远程监控系统中报警传输网络的通信协议，包括数据包结构、编码方式、传输规则等核心内容。然而，在实际开发和测试过程中，缺乏专业的协议模拟工具，导致：

- 平台开发阶段无法进行有效的端到端测试
- 协议实现正确性难以验证
- 复杂场景下的系统稳定性测试困难
- 新设备接入时缺乏标准化的测试手段

## 项目愿景

**FireLink Pro** 致力于成为智慧消防领域最专业、最易用的通信协议测试平台：

- **标准合规**: 严格遵循 GB/T 26875.3-2011 国家标准，确保协议实现的准确性
- **场景丰富**: 覆盖从单点报警到复杂联动的全场景模拟能力
- **可视化体验**: 提供直观的 Web 界面，降低使用门槛
- **开放接口**: 支持 RESTful API 和 WebSocket，便于集成到自动化测试流程
- **持续演进**: 跟踪行业标准更新，支持更多消防通信协议

我们相信，通过专业的测试工具赋能，可以帮助更多企业和开发者构建更可靠、更智能的消防监控系统，为城市安全保驾护航。

## 功能特性

### 场景模拟
- **正常状态** - 设备正常监视状态
- **单点火灾报警** - 单个探测器火警
- **确认火警** - 多点同时报警（确认火警）
- **故障报警** - 设备故障
- **复合报警** - 火警+故障同时发生
- **模拟量超限** - 温度/烟雾浓度超限
- **系统级火警** - 整个系统火警状态
- **装置火警** - 传输装置火警状态
- **完整火灾场景** - 完整火灾序列（4个数据包）
- **随机场景** - 随机生成一种场景

### 网络功能
- 支持 TCP/UDP 发送
- 自动发送模式（可配置间隔）
- 实时发送日志
- 发送历史记录

### 数据包解析
- 实时解析数据包结构
- 十六进制显示
- 字段级详情展示
- 一键复制 HEX

## 使用说明

### 基本操作

1. **选择场景**: 点击左侧场景卡片选择要模拟的火警场景
2. **查看数据包**: 选择场景后，数据包详情会自动显示在下方
3. **发送数据**: 点击"发送数据包"按钮将数据发送到目标服务器
4. **复制HEX**: 点击"复制HEX"可复制原始十六进制数据

### 网络配置

- **目标主机**: 接收数据的服务器地址
- **目标端口**: 接收数据的服务器端口
- **传输协议**: TCP 或 UDP
- **源地址**: 数据包源地址

### 自动发送

1. 选择要循环发送的场景
2. 设置发送间隔（秒）
3. 点击"开始"启动自动发送
4. 点击"停止"结束自动发送

### 发送历史

- 显示最近的发送记录
- 包含场景名称、发送时间、结果状态
- 支持刷新和清空操作

## 协议实现

### 数据包结构

```
+------------+-------------------+---------------+-----------+------------+
| 启动符(2B) |     控制单元(25B)  | 应用数据单元  | 校验和(1B) | 结束符(2B) |
|   @@       |                  |   (变长)      |           |    ##      |
+------------+-------------------+---------------+-----------+------------+
```

### 控制单元结构

- 业务流水号 (2字节)
- 协议版本号 (2字节)
- 时间标签 (6字节)
- 源地址 (6字节)
- 目的地址 (6字节)
- 应用数据单元长度 (2字节)
- 命令字节 (1字节)

### 应用数据单元

- 类型标志 (1字节)
- 信息对象数目 (1字节)
- 信息对象 (变长)

## API 接口

### HTTP API

- `GET /api/scenes` - 获取场景列表
- `GET /api/stats` - 获取统计信息
- `GET /api/history` - 获取发送历史
- `POST /api/clear_history` - 清空历史

### WebSocket 事件

- `generate_packet` - 生成数据包
- `send_packet` - 发送数据包
- `start_auto_send` - 开始自动发送
- `stop_auto_send` - 停止自动发送

## 技术栈

- **后端**: Python + Flask + Flask-SocketIO
- **前端**: HTML5 + CSS3 + JavaScript
- **通信**: WebSocket + Socket.IO
- **协议**: GBT 26875.3-2011

## 注意事项

1. 确保目标服务器已启动并监听指定端口
2. TCP 模式需要目标服务器接受连接
3. UDP 模式不需要预先建立连接
4. 自动发送间隔最小为 1 秒
