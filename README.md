# GBT 26875.3-2011 消防报警数据模拟器 (Web可视化版)

基于 GBT 26875.3-2011 标准的城市消防远程监控系统报警传输网络通信协议模拟工具，提供 Web 可视化界面，用于测试火警分级引擎。

## 功能特性

### 场景模拟
- **正常状态** - 设备正常监视状态
- **单点火灾报警** - 单个探测器火警
- **确认火警** - 多点同时报警（确认火警）
- **故障报警** - 设备故障
- **复合报警** - 火警+故障同时发生
- **模拟量超限** - 温度/烟雾浓度超限
- **系统级火警** - 整个系统火警状态
- **装置火警** - 传输装置火警状态
- **完整火灾场景** - 完整火灾序列（4个数据包）
- **随机场景** - 随机生成一种场景

### 网络功能
- 支持 TCP/UDP 发送
- 自动发送模式（可配置间隔）
- 实时发送日志
- 发送历史记录

### 数据包解析
- 实时解析数据包结构
- 十六进制显示
- 字段级详情展示
- 一键复制 HEX

## 安装运行

### 1. 安装依赖

```bash
cd fire_alarm_simulator
pip install -r requirements.txt
```

### 2. 启动服务

```bash
python app.py
```

### 3. 访问界面

打开浏览器访问: http://127.0.0.1:5000

## 使用说明

### 基本操作

1. **选择场景**: 点击左侧场景卡片选择要模拟的火警场景
2. **查看数据包**: 选择场景后，数据包详情会自动显示在下方
3. **发送数据**: 点击"发送数据包"按钮将数据发送到目标服务器
4. **复制HEX**: 点击"复制HEX"可复制原始十六进制数据

### 网络配置

- **目标主机**: 接收数据的服务器地址
- **目标端口**: 接收数据的服务器端口
- **传输协议**: TCP 或 UDP
- **源地址**: 数据包源地址

### 自动发送

1. 选择要循环发送的场景
2. 设置发送间隔（秒）
3. 点击"开始"启动自动发送
4. 点击"停止"结束自动发送

### 发送历史

- 显示最近的发送记录
- 包含场景名称、发送时间、结果状态
- 支持刷新和清空操作

## 协议实现

### 数据包结构

```
+------------+-------------------+---------------+-----------+------------+
| 启动符(2B) |     控制单元(25B)  | 应用数据单元  | 校验和(1B) | 结束符(2B) |
|   @@       |                  |   (变长)      |           |    ##      |
+------------+-------------------+---------------+-----------+------------+
```

### 控制单元结构

- 业务流水号 (2字节)
- 协议版本号 (2字节)
- 时间标签 (6字节)
- 源地址 (6字节)
- 目的地址 (6字节)
- 应用数据单元长度 (2字节)
- 命令字节 (1字节)

### 应用数据单元

- 类型标志 (1字节)
- 信息对象数目 (1字节)
- 信息对象 (变长)

## API 接口

### HTTP API

- `GET /api/scenes` - 获取场景列表
- `GET /api/stats` - 获取统计信息
- `GET /api/history` - 获取发送历史
- `POST /api/clear_history` - 清空历史

### WebSocket 事件

- `generate_packet` - 生成数据包
- `send_packet` - 发送数据包
- `start_auto_send` - 开始自动发送
- `stop_auto_send` - 停止自动发送

## 技术栈

- **后端**: Python + Flask + Flask-SocketIO
- **前端**: HTML5 + CSS3 + JavaScript
- **通信**: WebSocket + Socket.IO
- **协议**: GBT 26875.3-2011

## 注意事项

1. 确保目标服务器已启动并监听指定端口
2. TCP 模式需要目标服务器接受连接
3. UDP 模式不需要预先建立连接
4. 自动发送间隔最小为 1 秒
